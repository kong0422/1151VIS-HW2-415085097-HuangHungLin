## 功能

### 地圖

- 以縣市 TopoJSON（`taiwan-atlas`）繪製台灣各縣市邊界，包含澎湖、金門、連江。
- 縣市底色直接代表數值（色塊圖），沒有資料的縣市顯示灰色；預設就有一組範例資料，開啟即可看到完整畫面。
- **顏色圖例放在地圖左下角**（字體與色條已加大），疊在地圖上，不會擋住滑鼠操作。
- 滾輪縮放（1–14 倍）、拖曳平移；縮放時文字與圖示會自動調整大小。
- 滑鼠移到縣市會高亮邊框，點擊可選取（與右側排行連動）。
- 可開關「顯示縣市名稱與數值」與「顯示天氣圖示」。
- 若縣市邊界自動載入失敗，頁面會列出各來源的錯誤原因，並提供檔案選擇鈕，可自行選擇 TopoJSON / GeoJSON 檔。

### 指標切換

上方按鈕可切換地圖底色所代表的指標：

| 指標 | 色階 | 說明 |
|---|---|---|
| 氣溫 | 藍（冷）→ 黃 → 紅（熱），0–35 °C | 縣市內測站平均 |
| 日照時數 | 淺黃 → 深褐，**色階上限依目前資料自動調整** | 縣市內測站平均，單位小時 |
| 降雨機率 | 白 → 深藍，0–100 % | 36 小時預報最近一個時段 |

日照時數的色階上限會依資料自動決定：讀數都在 1 以內（每小時值）時上限為 1，否則取 2 的倍數（例如最大 9.3 → 10），所以不論氣象署回傳的是每小時值還是當日累積值，顏色都看得出差異；圖例會同步顯示目前的範圍。

**紫外線**（分級：低量級 0–2、中量級 3–5、高量級 6–7、過量級 8–10、危險級 ≥11；優先使用「今日最大值」）與**累積雨量**（當日，mm）目前只顯示在提示窗與長條圖，不出現在切換按鈕。若想把它們改回按鈕，把 `METRICS.uv` 或 `METRICS.acc` 裡的 `tipOnly: true` 拿掉即可。

### 提示窗

滑鼠移到縣市（或點擊縣市）會出現提示窗，內容為：

- 縣市名稱
- 天氣現象（圖示 + 文字）
- 氣溫、日照時數、降雨機率、紫外線（含級別）、累積雨量；每行前的小色塊是該數值對應的顏色，目前選擇的指標會以黃色標示
- 多個測站的縣市會標註「N 站平均」；沒有資料的項目顯示「無資料」

### 右側排行

依目前選擇的指標，列出各縣市平均值由高到低的排行，並附天氣圖示。

### 框選縣市與長條圖快顯視窗（d3.brush）

1. 按地圖上方的「框選模式」把它打開。
2. 在地圖上拖曳畫出矩形，矩形內的縣市會被選取，並以粉紅色邊框標示。判斷方式是「縣市中心點是否落在矩形內」，縮放或平移後依然準確。
3. **放開滑鼠後，會跳出「選取縣市長條圖」快顯視窗**：由高到低排序，長條顏色與地圖相同，並附天氣圖示與數值，沒有資料的縣市顯示「無資料」。
4. 視窗右上角的「指標」可選擇氣溫、日照時數、降雨機率、紫外線、累積雨量，預設會跟著地圖目前的指標。
5. 視窗可以**按住標題列拖曳**到想要的位置（預設在右下角）；再次框選時視窗會即時更新。
6. 按視窗右上角的「×」關閉視窗，選取的縣市仍會保留，地圖上方會出現「顯示長條圖」按鈕可再次打開；按「清除選取」，或在地圖上單擊一下空白處，則會取消選取並關閉視窗。

注意：框選模式開啟時，滑鼠拖曳用來框選，不能平移，也不會出現提示窗；**滾輪縮放仍可使用**。要平移或查看提示窗時，把框選模式關掉即可（已選取的縣市會保留）。

### 天氣圖示

圖示使用 emoji，不需額外載入圖片。依天氣現象文字對應：

| 天氣文字（範例） | 圖示 |
|---|---|
| 晴 | ☀️ |
| 晴時多雲、多雲時晴 | 🌤️ |
| 多雲 | ⛅ |
| 陰 | ☁️ |
| 陰有雨、陰短暫雨 | 🌧️ |
| 多雲時晴短暫雨（含「雨」且含「晴」或「多雲」） | 🌦️ |
| 含「雷」 | ⛈️ |
| 含「雪」 | 🌨️ |
| 含「霧」 | 🌫️ |
| 其他 | 🌡️ |

### 資料載入方式

頁面開啟時**預設顯示一組範例資料**（22 個縣市、29 個測站的示意值，不是真實觀測），讓你不用任何設定就能看到完整畫面。要換成真實資料，有兩種方式：

1. **內嵌資料（建議）**：執行 `python3 fetch_data.py --embed`，由 Python 抓取氣象署資料並寫進 HTML，之後雙擊開啟即可使用。
2. **直接呼叫氣象署**：在頁面輸入授權碼，按「載入即時資料」。瀏覽器可能因 CORS 限制而失敗（見[疑難排解](#疑難排解)）。

頁面上的「資料：…」那一行會標示每項資料目前的來源：「範例資料」、「CSV：內嵌資料 觀測時間」或「中央氣象署觀測／預報」。

## 快速開始

### 方式 A：先用腳本抓資料並內嵌（建議）

Python 呼叫氣象署 API 不受瀏覽器的 CORS 限制。

1. 申請氣象署開放資料授權碼（免費）：<https://opendata.cwa.gov.tw>
2. 把 `fetch_data.py` 與 `taiwan-temp-map.html` 放在同一個資料夾。
3. 執行（Python 3，只使用標準函式庫，不需安裝套件）：

   ```bash
   CWA_KEY=CWA-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx python3 fetch_data.py --embed
   ```

   （Windows PowerShell：`$env:CWA_KEY="CWA-..."; python fetch_data.py --embed`）
4. 直接雙擊開啟 `taiwan-temp-map.html`。

要更新資料就重新執行一次；也可以加上 `--interval 600` 每 10 分鐘更新一次，重新整理頁面即可看到新資料。

### 方式 B：在頁面輸入授權碼

直接開啟 `taiwan-temp-map.html`，在上方輸入框填入授權碼，按「載入即時資料」。授權碼會存在瀏覽器的 localStorage，下次開啟時會自動抓取，並每 10 分鐘更新一次。

若瀏覽器擋下呼叫（CORS），請改用方式 A。

## 設定

### 頁面（`taiwan-temp-map.html`）

| 項目 | 位置 | 說明 |
|---|---|---|
| `DEFAULT_KEY` | script 開頭 | 預設授權碼。分享檔案前請清空，見[安全注意事項](#安全注意事項) |
| `EMBEDDED` | `/*EMBED_START*/ … /*EMBED_END*/` 之間 | 內嵌資料，由 `fetch_data.py --embed` 寫入，請勿手動修改 |
| `URLS` | script 開頭 | 縣市 TopoJSON 來源，依序嘗試（jsDelivr → unpkg） |
| `METRICS` | script 開頭 | 各指標的名稱、色階、數值格式；`tipOnly: true` 表示只顯示在提示窗與長條圖 |
| `refreshMs` | `data()` | 即時資料更新間隔，預設 600000（10 分鐘） |

### 資料載入的優先順序

資料由低到高的優先順序是：**預設範例資料 → 內嵌資料 → 即時資料**，每個指標各自獨立取代。

- **預設**：顯示內建的範例資料（頁面上方會提示「目前顯示的是範例資料」）。
- **有內嵌資料時**：開啟頁面不會自動連線，直接顯示內嵌資料（內嵌資料裡有的指標會取代範例，沒有的指標仍保留範例）；仍可手動按「載入即時資料」，抓到的指標會**逐項取代**內嵌的值。
- **沒有內嵌資料、但有授權碼時**：開啟時自動抓取，之後每 10 分鐘更新。
- **抓不到的指標**維持原有資料（範例或內嵌），並在頁面上方顯示失敗原因。

## 資料來源與欄位

以下資料集皆來自[中央氣象署氣象資料開放平臺](https://opendata.cwa.gov.tw)（授權方式：政府資料開放授權條款－第1版）。

| 資料集 | 用途 | 使用的欄位 |
|---|---|---|
| `O-A0003-001` 現在天氣觀測報告（每 10 分鐘更新） | 氣溫、累積雨量、日照時數、天氣現象、測站對照 | `AirTemperature`、`Now.Precipitation`、`SunshineDuration`、`Weather`、`StationId`、`StationName`、`GeoInfo.CountyName`、`ObsTime.DateTime`；`UVIndex`（即時讀數，作為紫外線的備援） |
| `O-A0005-001` 紫外線指數－每日最大值 | 紫外線（主要來源） | `weatherElement.location[].StationID`、`UVIndex`；`weatherElement.Date` |
| `F-C0032-001` 36 小時天氣預報 | 降雨機率、天氣現象（補觀測缺漏的縣市） | `PoP`（降雨機率）、`Wx`（天氣現象），取最近一個時段 |

### 縣市彙整方式

- 同一縣市有多個測站時，取**算術平均**（不依面積或人口加權）。
- 縣市名稱比對時會把「台」統一成「臺」。
- 缺值（負值，如 `-99`）會略過；累積雨量的 `-998`（微量）以 0 計。
- 紫外線的「每日最大值」資料只有測站代碼，程式會用 `O-A0003-001` 的測站清單把代碼對應到縣市。若只能取得即時讀數且全為 0（夜間），視為沒有資料。
- 天氣現象：同縣市多站時取最常出現者；觀測沒有有效天氣的縣市，改用預報的 `Wx` 補上。

## fetch_data.py

直接呼叫氣象署 API，不經過瀏覽器：

```bash
python3 fetch_data.py                   # 抓一次，存成檔案
python3 fetch_data.py --embed           # 同時把縣市資料寫進 taiwan-temp-map.html
python3 fetch_data.py --embed 其他.html  # 寫進指定的 HTML
python3 fetch_data.py --interval 600    # 每 10 分鐘重複一次（Ctrl+C 結束）
python3 fetch_data.py --history         # 另外留一份帶時間戳記的歷史檔
python3 fetch_data.py --key CWA-xxxx    # 指定授權碼（預設讀環境變數 CWA_KEY）
```

執行後會在 `./data/`（可用 `--out` 改）產生：

| 檔案 | 內容 |
|---|---|
| `county_weather.csv` | 縣市彙整：縣市、氣溫、日照時數、降雨機率、紫外線、累積雨量、氣溫測站數、天氣 |
| `station_obs.csv` | 測站明細：測站、縣市、氣溫、紫外線、累積雨量、日照時數 |
| `raw/O-A0003-001.json` 等 | 氣象署原始回傳，方便自行分析或除錯 |

CSV 開頭帶有編碼標記，用 Excel 直接開啟中文不會亂碼。腳本的彙整規則與頁面相同；執行時會逐項顯示三個資料集成功或失敗的原因。若現在天氣觀測（`O-A0003-001`）沒抓到，則不會產生檔案並以非 0 狀態結束。

### 內嵌（`--embed`）

- 資料寫在 HTML 內 `/*EMBED_START*/ … /*EMBED_END*/` 標記之間，每次執行都會覆蓋上一次的內容。
- 頁面上的資料來源會顯示「CSV：內嵌資料 觀測時間」。
- 內嵌的是**某個時間點的快照**，不會自動更新；內嵌的是縣市層級資料，不含測站明細。

## 資料整理與製作過程

這一節記錄資料從氣象署到地圖畫面的整理流程，以及專案一路做下來的過程與取捨。

### 一、資料取得

1. **選資料集**：以「縣市」為單位呈現，所以選了能對應到縣市的三個氣象署資料集（`O-A0003-001` 現在天氣觀測、`O-A0005-001` 紫外線每日最大值、`F-C0032-001` 36 小時預報），欄位依官方欄位說明文件與資料集說明頁確認。
2. **取得縣市邊界**：使用 `taiwan-atlas` 的縣市 TopoJSON，由 `topojson-client` 轉成 GeoJSON 後交給 D3 繪製。
3. **取得方式**：氣象署 API 需要授權碼，瀏覽器直接呼叫又常被 CORS 擋下，所以最後以 `fetch_data.py` 在本機抓取（Python 不受 CORS 限制），可輸出 CSV / JSON，或把縣市彙整資料直接內嵌進 HTML。

### 二、資料清理與彙整

原始資料是「測站層級」，畫面是「縣市層級」，中間做了這些處理：

| 步驟 | 處理方式 | 原因 |
|---|---|---|
| 缺值過濾 | 負值（如 `-99`）視為缺值並略過；氣溫限定在 -50～60 °C、日照 0～24 小時、雨量 0～1500 mm | 排除感測器故障或無感測器的測站 |
| 微量雨量 | 累積雨量 `-998`（微量）以 0 計 | 避免把「有下一點點雨」當成缺值 |
| 縣市名稱正規化 | 比對時把「台」統一成「臺」 | 不同資料來源寫法不一致，避免對不起來 |
| 測站 → 縣市 | 取各測站所屬縣市的**算術平均** | 簡單、可解釋；不依面積或人口加權 |
| 紫外線對應 | 每日最大值資料只有測站代碼，用 `O-A0003-001` 的測站清單把代碼對應回縣市 | 該資料集沒有縣市欄位 |
| 紫外線全為 0 | 若只取得即時讀數且全部是 0，視為沒有資料 | 夜間與日出前後的即時讀數本來就是 0，畫出來會誤導成「紫外線為 0」 |
| 天氣現象 | 同縣市多站取最常出現者；觀測沒有有效文字的縣市改用預報 `Wx` 補上 | 自動站常缺 `Weather` 欄位 |
| 降雨機率 | 取 36 小時預報最近一個時段的 `PoP` | 預報本身就是縣市層級，不需再平均 |
| 日照時數色階 | 色階上限依目前資料自動決定（≤1 → 1，否則取 2 的倍數） | 尚未確認該欄位是每小時值還是當日累積值，自動適應才不會整張圖顏色糊成一片 |

整理後的縣市資料格式與 `county_weather.csv` 相同（縣市、氣溫、日照時數、降雨機率、紫外線、累積雨量、氣溫測站數、天氣），也是內嵌進頁面的格式。

### 三、視覺化設計

- **色塊圖而不是泡泡圖**：最早的版本是泡泡圖（顏色與大小都代表氣溫），後來改成縣市底色，數值一目了然，也不會有泡泡互相遮蓋的問題。
- **色階**：氣溫用藍→黃→紅（冷熱直覺）；日照時數用淺黃→深褐；降雨機率用白→藍；紫外線依氣象署的 5 級分級用離散色塊。
- **圖例**：疊在地圖左下角（避開有縣市的區域），字體與色條加大，並設成不攔截滑鼠事件，不影響地圖操作。
- **提示窗**：把五項指標與天氣放在同一個窗，不必來回切換就能比較；沒有資料明確顯示「無資料」。
- **天氣圖示**：用 emoji，不額外載入圖片；依天氣文字關鍵字（雷、雪、雨、霧、陰、晴、多雲）對應。
- **框選與長條圖**：用 `d3.brush` 框選縣市，放開滑鼠後跳出可拖曳的長條圖視窗；因為縮放會改變畫面座標，判斷時把各縣市中心點套上目前的縮放轉換再比對。框選層放在縮放群組之外，並讓框選模式下的拖曳不觸發平移。

### 四、製作歷程

### 五、驗證方式與限制

- 開發環境**無法連線到氣象署**，所以資料彙整邏輯（缺值過濾、縣市平均、紫外線對應、內嵌寫入與讀回、CSV 解析）是用依官方欄位格式自行構造的模擬資料測試，並用腳本檢查語法與 Vue 的參數／模板綁定是否一致。
- 地圖繪製、框選手感、視窗位置等畫面行為，需在實際瀏覽器中確認。
- 部分氣象署欄位（`O-A0005-001` 的實際結構、`Now.Precipitation` 與 `SunshineDuration` 的確切意義、`Weather`／`Wx` 的格式）尚未以真實回傳內容驗證；程式遇到不符預期的結構時，會在畫面或 `fetch_data.py` 的輸出中列出回傳欄位，方便據以調整。
- 範例資料是示意值，僅用來在沒有真實資料時展示畫面。

### 六、設計取捨小結

- **單一 HTML 檔**：不需要建置工具，雙擊就能開；代價是依賴 CDN 載入函式庫。
- **內嵌快照 vs. 即時抓取**：因為瀏覽器端直接呼叫氣象署常被 CORS 擋下，選擇讓 Python 抓資料再內嵌；代價是資料不會自動更新，需重新執行腳本。
- **簡單平均**：容易說明，但測站分布不均時可能偏離實際縣市狀況。
- **資料逐項取代**：任何一項資料抓不到時，其他項目照常顯示，不會整頁壞掉。

## 程式結構

`taiwan-temp-map.html` 使用 Vue 3 的 Options API：

| 區塊 | 內容 |
|---|---|
| `data()` | 所有參數與狀態：`metric`、`apiKey`、`datasets`、`weather`、`sources`、`status`、`msg`、`tip`、`sel`、`showLabels`、`showIcons`、`brushMode`、`picked`、`chartMetric`、`popupOpen`、`popupPos` 等 |
| `computed` | `M`（目前指標設定）、`records`、`hasData`、`weatherMap`、`allAvg`、`avgMap`、`sunMax`、`rows` |
| `watch` | 指標、顯示開關、選取縣市、框選結果與平均值變動時重繪（含圖例與長條圖） |
| `created` | 讀取授權碼、套用內嵌資料、必要時抓即時資料並設定定時更新 |
| `mounted` | 畫圖例、長條圖、載入縣市邊界（需要 DOM 才能做） |
| `methods` | 地圖繪製（`render`、`paint`、`updateScale`、`drawLegend`）、框選與長條圖（`onBrush`、`drawBars`、`startDrag`）、資料載入（`loadMap`、`cwa`、`loadLive`、`applyCsv`）、提示窗等 |

D3 的繪圖物件與拖曳狀態（`g`、`labelG`、`iconG`、`brush`、`brushG`、`zoomT`、`centroids`、`curK`、`drag`）刻意放在 `created` 設成實例屬性，**不放進 `data()`**，避免 D3 selection 被 Vue 轉成響應式代理而出問題。

## 疑難排解

| 現象 | 可能原因與處理 |
|---|---|
| 地圖沒出現、上方顯示「地圖自動載入失敗」 | 無法連到 jsDelivr / unpkg。檢查網路，或自行下載縣市 TopoJSON / GeoJSON，用頁面上的檔案選擇鈕載入 |
| 顯示的是範例資料 | 這是預設行為。要看真實資料，執行 `python3 fetch_data.py --embed`，或填入授權碼按「載入即時資料」 |
| 出現 `NetworkError` / `Failed to fetch` | 瀏覽器擋下直接呼叫氣象署（CORS）。改用 `python3 fetch_data.py --embed` |
| 「氣象署回應 HTTP 401/403」 | 授權碼錯誤或已失效 |
| 紫外線沒有資料或數值全是 0 | 若是夜間，即時讀數為 0 屬正常（全為 0 時視為沒有資料）。白天仍沒有資料時，請看頁面上方（或 `fetch_data.py` 輸出）的紫外線訊息，裡面會列出回傳欄位以便調整解析 |
| 某一項顯示「回傳資料中沒有有效數值」 | 該欄位暫時沒有資料，或欄位格式與預期不同 |
| 框選時沒有跳出長條圖 | 確認「框選模式」是開啟的，且矩形內有縣市的中心點；視窗被關閉時可按「顯示長條圖」 |
| `--embed` 回報找不到標記 | HTML 不是最新版，缺少 `/*EMBED_START*/ … /*EMBED_END*/` |

## 已知限制

- 以下氣象署欄位是依官方欄位說明文件撰寫，**尚未在所有情況下以真實回傳內容驗證**：`O-A0005-001` 的 `weatherElement.location` 結構、`Now.Precipitation` 是否為當日累積雨量、`Weather` 與 `Wx` 的內容格式。若載入後某一項不正常，請依訊息調整 `loadLive()`（頁面）或 `summarize()`（`fetch_data.py`）的解析。
- 日照時數取自 `O-A0003-001` 的 `SunshineDuration`；它是「每小時值」還是「當日累積值」尚未確認。頁面的色階會自動適應，但提示窗顯示的「N 小時」若是每小時值，代表的是最近一小時的日照。
- 預設的範例資料是示意值，不是真實觀測，請勿當成實際天氣。
- 縣市平均是各測站的簡單平均，沒有測站的縣市可能沒有資料。
- 降雨機率是縣市預報，不是測站觀測，與其他觀測值的時間意義不同。
- 框選是以縣市中心點判斷，有離島的縣市以中心點位置為準。
- 需要連網才能載入 Vue、D3 與縣市邊界。
- 天氣圖示使用 emoji，外觀依作業系統與瀏覽器而異。

## 安全注意事項

- `DEFAULT_KEY`（`taiwan-temp-map.html`）與 `fetch_data.py` 內的預設授權碼若寫有授權碼，**分享、上傳或提交檔案前請先清空**，改用輸入框或 `CWA_KEY` 環境變數。
- 授權碼一旦外洩，請到氣象署開放資料平台重新產生。
- 若使用版本控制，建議不要提交含授權碼的檔案。
- 在頁面輸入授權碼時，授權碼會存在瀏覽器的 localStorage（鍵名 `cwa_key`），公用電腦請避免使用。

## 資料授權

氣象資料來自中央氣象署開放資料平台，依「政府資料開放授權條款－第1版」提供，使用時請遵守該授權條款與氣象署的使用規範。縣市邊界資料來自 `taiwan-atlas` 套件，請依其授權使用。
