> 以 **Vue 3.5 + D3.js + TopoJSON** 製作的台灣縣市氣象地圖。每個縣市依「轄內測站的平均值」直接填上顏色。
> 延續第一次作業，增加拖曳框選功能(brushing)，框選的縣市會顯示彈跳視窗，並加入長條圖(bar chart)並以升序排序選取的資料，
> 還可依照下拉選單切換指標（氣溫、累積雨量、日照時數、紫外線指數、天氣現象）。
> 調整首頁指標切換把紫外線先改成日照時數，避免氣象觀測站回傳紫外線為 0 的情況，因為太陽下山後紫外線的即時資料為 0。

## 功能

### 一、地圖

- 以縣市 TopoJSON（`taiwan-atlas`）繪製台灣各縣市邊界，包含澎湖、金門、連江。
- 縣市底色直接代表數值（色塊圖），沒有資料的縣市顯示灰色；預設就有一組範例資料，開啟即可看到完整畫面。
- **顏色圖例放在地圖左下角**（字體與色條已加大），疊在地圖上，不會擋住滑鼠操作。
- 滾輪縮放（1–14 倍）、拖曳平移；縮放時文字與圖示會自動調整大小。
- 滑鼠移到縣市會高亮邊框，點擊可選取（與右側排行連動）。
- 可開關「顯示縣市名稱與數值」與「顯示天氣圖示」。

### 二、指標切換

上方按鈕可切換地圖底色所代表的指標：

| 指標 | 色階 | 說明 |
|---|---|---|
| 氣溫 | 藍（冷）→ 黃 → 紅（熱），0–35 °C | 縣市內測站平均 |
| 日照時數 | 淺黃 → 深褐，**色階上限依目前資料自動調整** | 縣市內測站平均，單位小時 |
| 降雨機率 | 白 → 深藍，0–100 % | 36 小時預報最近一個時段 |

### 三、提示窗

滑鼠移到縣市（或點擊縣市）會出現提示窗，內容為：

- 縣市名稱
- 天氣現象（圖示 + 文字）
- 氣溫、日照時數、降雨機率、紫外線（含級別）、累積雨量；每行前的小色塊是該數值對應的顏色，目前選擇的指標會以黃色標示
- 多個測站的縣市會標註「N 站平均」

### 四、右側縣市清單

依目前選擇的指標，列出各縣市平均值由高到低的排行，並附天氣圖示。

### 五、框選縣市與長條圖快顯視窗（d3.brush）

1. 按地圖上方的「框選模式」把它打開。
2. 在地圖上拖曳畫出矩形，矩形內的縣市會被選取，並以粉紅色邊框標示。判斷方式是「縣市中心點是否落在矩形內」，縮放或平移後依然準確。
3. **放開滑鼠後，會跳出「選取縣市長條圖」快顯視窗**：由高到低排序，長條顏色與地圖相同，並附天氣圖示與數值，沒有資料的縣市顯示「無資料」。
4. 視窗右上角的「指標」可選擇氣溫、日照時數、降雨機率、紫外線、累積雨量，預設會跟著地圖目前的指標。
5. 視窗可以**按住標題列拖曳**到想要的位置（預設在右下角）；再次框選時視窗會即時更新。
6. 按視窗右上角的「×」關閉視窗，選取的縣市仍會保留，地圖上方會出現「顯示長條圖」按鈕可再次打開；按「清除選取」，或在地圖上單擊一下空白處，則會取消選取並關閉視窗。

注意：框選模式開啟時，滑鼠拖曳會變成框選，不會出現提示窗；**滾輪縮放仍可使用**。要平移或查看提示窗時，把框選模式關掉即可（已選取的縣市會保留）。

### 六、天氣圖示

圖示使用 emoji，不需額外載入圖片。依天氣現象文字對應：

| 天氣文字（範例） | 圖示 |
|---|---|
| 晴 | ☀️ |
| 晴時多雲、多雲時晴 | 🌤️ |
| 多雲 | ⛅ |
| 陰 | ☁️ 
| 陰有雨、陰短暫雨 | 🌧️ |
| 多雲時晴短暫雨（含「雨」且含「晴」或「多雲」） | 🌦️ |
| 含「雷」 | ⛈️ |
| 含「雪」 | 🌨️ |
| 含「霧」 | 🌫️ |
| 其他 | 🌡️ |

### 七、資料載入方式

頁面開啟時**預設顯示一組範例資料**（22 個縣市、29 個測站的示意值，不是真實觀測），頁面開啟時會先跑一次API去抓取觀測資料，先放預設資料是為了避免因為網路問題API抓不到資料而無法顯示地圖, 
資料更新方式有兩種：
 - **自動更新** ：每隔10分鐘會呼叫更新的資料API，並更新頁面上最後資料時間。 
 - **直接呼叫氣象署**：點擊「載入即時資料」的按紐便會立即呼叫更新的資料API。

## 資料整理與製作過程

### 一、資料取得

1. **選資料集**：以「縣市」為單位呈現，所以選了能對應到縣市的三個氣象署資料集（`O-A0003-001` 現在天氣觀測、`O-A0005-001` 紫外線每日最大值、`F-C0032-001` 36 小時預報），欄位依官方欄位說明文件與資料集說明頁確認。
2. **取得縣市邊界**：使用 `taiwan-atlas` 的縣市 TopoJSON，由 `topojson-client` 轉成 GeoJSON 後交給 D3 繪製。
3. **取得方式**：氣象署 API 需要先註冊帳號申請授權碼。

### 二、資料清理與彙整

原始資料是以「觀測站」為主，視覺化用使體是「縣市」為主，中間做了這些處理：

| 步驟 | 處理方式 | 原因 |
|---|---|---|
| 缺值過濾 | 負值（如 `-99`）視為缺值並略過；氣溫限定在 -50～60 °C、日照 0～24 小時、雨量 0～1500 mm | 排除感測器故障或無感測器的測站 |
| 微量雨量 | 累積雨量 `-998`（微量）以 0 計 | 避免出現負值 |
| 縣市名稱正規化 | 比對時把「台」統一成「臺」 | 不同資料來源寫法不一致，避免整理資料無法對同縣市無法正常對應 |
| 測站 → 縣市 | 取各測站所屬縣市的**算術平均** | 每個縣市的觀測站不一定 |
| 紫外線對應 | 每日最大值資料只有測站代碼，用 `O-A0003-001` 的測站清單把代碼對應回縣市 | 該資料集沒有縣市欄位 |
| 紫外線全為 0 | 若只取得即時讀數且全部是 0，視為沒有資料 | 夜間與日出前後的即時讀數本來就是 0，畫出來會誤導成「紫外線為 0」 |
| 天氣現象 | 同縣市多站取最常出現者；觀測沒有有效文字的縣市改用預報 `Wx` 補上 | 自動站常缺 `Weather` 欄位 |
| 降雨機率 | 取 36 小時預報最近一個時段的 `PoP` | 預報本身就是縣市層級，不需再平均 |
| 日照時數色階 | 色階上限依目前資料自動決定（≤1 → 1，否則取 2 的倍數） | 尚未確認該欄位是每小時值還是當日累積值，自動適應才不會整張圖顏色糊成一片 |

整理後的縣市資料格式CSV（縣市、氣溫、日照時數、降雨機率、紫外線、累積雨量、氣溫測站數、天氣），也是本來打算使用資料內嵌放進頁面的格式。

### 三、視覺化設計

- **色塊圖而不是泡泡圖**：最早的版本是泡泡圖（顏色與大小都代表氣溫），後來改成縣市底色，數值一目了然，也不會有泡泡互相遮蓋的問題。
- **色階**：氣溫用藍→黃→紅（冷熱直覺）；日照時數用淺黃→深褐；降雨機率用白→藍；紫外線依氣象署的 5 級分級用離散色塊。
- **圖例**：疊在地圖右邊（避開有縣市的區域），字體與色條加大，並設成不攔截滑鼠事件，不影響地圖操作。
- **提示窗**：把五項指標與天氣放在同一個窗，不必來回切換就能比較；沒有資料明確顯示「無資料」。
- **天氣圖示**：用 emoji，不額外載入圖片；依天氣文字關鍵字（雷、雪、雨、霧、陰、晴、多雲）對應。
- **框選與長條圖**：用 `d3.brush` 框選縣市，放開滑鼠後跳出可拖曳的長條圖視窗；因為縮放會改變畫面座標，判斷時把各縣市中心點套上目前的縮放轉換再比對。框選層放在縮放群組之外，並讓框選模式下的拖曳不觸發平移。

### 四、製作歷程

| 階段 | 做了什麼 | 遇到的問題與處理 |
|---|---|---|
| 1. 原型 | 用 Vue + D3 做台灣溫度泡泡圖，內建手繪簡化輪廓與範例溫度 | 預覽環境不能連外，所以資料是示意值 |
| 2. 縣市邊界 | 改用 TopoJSON 縣市邊界 | 地圖一度沒出現：`topojson-client` 的 CDN 路徑錯誤，改為固定版本的 jsDelivr 並加備援；另外加入多邊形方向修正與已投影座標的處理 |
| 3. 色塊圖 | 泡泡改成縣市底色（縣市測站平均），加入縣市名稱與數值標示 | 縣市名稱「台／臺」不一致，統一為「臺」 |
| 4. 多指標 | 新增氣溫／紫外線／降雨機率切換；提示窗顯示全部指標；再加入累積雨量與日照時數 | 把整理好的資料都放入 `METRICS` 陣列，後續所有d3資料都從這邊輸出 |
| 5. 即時資料 | 接上氣象署 API，每 10 分鐘更新 | 太陽下山後氣象觀測資料紫外線只會是 0；改以 `O-A0005-001` 今日最大值為主，並把全 0 視為無資 |
| 6. 連線問題 | 瀏覽器直接呼叫出現 `NetworkError` | 加入預設資料確保網頁打開能正常顯示 |
| 7. 天氣圖示 | 新增天氣現象圖示 | 本來用天氣 icon 小圖，後來使用 emoji 文字，縮放更好控制 |
| 8. 功能調整 | 加入又移除 CSV 載入／下載；日照時數取代紫外線成為地圖指標（紫外線保留在提示窗與長條圖）；預設範例資料先移除後又恢復 | 依使用上的需求取捨：目前以「範例資料 → 內嵌資料 → 即時資料」逐項取代 |
| 9. 互動 | 加入 d3.brush 框選與長條圖快顯視窗；圖例移到左下角並放大 | 框選與縮放的拖曳衝突，以「框選模式」切換解決 |

### 五、設計取捨小結

- **先下載好的資料 vs. 即時抓取**：先下載好的資料不即時，也容易忘記更新，最後還是選擇透過API即時抓取。
- **指標平均**：簡單明確，但觀測站分布不均時可能偏離實際縣市狀況。
- **資料逐項取代**：任何一項資料抓不到時，其他項目照常顯示，不會整頁壞掉。

## 資料來源與欄位

以下資料集皆來自[中央氣象署氣象資料開放平臺](https://opendata.cwa.gov.tw)（授權方式：政府資料開放授權條款－第1版）。

| 資料集 | 用途 | 使用的欄位 |
|---|---|---|
| `O-A0003-001` 現在天氣觀測報告（每 10 分鐘更新） | 氣溫、累積雨量、日照時數、天氣現象、測站對照 | `AirTemperature`、`Now.Precipitation`、`SunshineDuration`、`Weather`、`StationId`、`StationName`、`GeoInfo.CountyName`、`ObsTime.DateTime`；`UVIndex`（即時讀數，作為紫外線的備援） |
| `O-A0005-001` 紫外線指數－每日最大值 | 紫外線（主要來源） | `weatherElement.location[].StationID`、`UVIndex`；`weatherElement.Date` |
| `F-C0032-001` 36 小時天氣預報 | 降雨機率、天氣現象（補觀測缺漏的縣市） | `PoP`（降雨機率）、`Wx`（天氣現象），取最近一個時段 |

氣象資料來自中央氣象署開放資料平台，依「政府資料開放授權條款－第1版」提供，使用時請遵守該授權條款與氣象署的使用規範。縣市邊界資料來自 `taiwan-atlas` 套件，請依其授權使用。
